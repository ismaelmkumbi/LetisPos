Product Menu — Implementation Architecture

Three missing features: Variants, Bundles/Kits, Price Lists

Feature Overview

1. Variants — Enhanced Product Form

Embedded in ProductDetailPage

Route: /smartpos/products/:id (existing)

Variant Matrix Builder
Attributes (Size, Color)
Generate Combos
Variant Grid: per-variant price, cost, barcode, image

Sidebar "Variants" → filtered product list

2. Bundles/Kits — New Page

New: BundlesListPage

Route: /smartpos/products/bundles

COMBO product grid with bundle cards
Create Bundle CTA
Bundle Cost Calculator
Component picker + qty + auto-pricing

Reuses ComboItemsEditor + Combo API

3. Price Lists — Full Stack (New)

Backend + Frontend

Routes: /smartpos/products/price-lists

PriceList entity: name, customerGroup, currency
PriceListLine: productId, variantId, price, minQty, maxQty
Customer Group Tiers
Quantity Breaks
Import/Export CSV for bulk price updates
Data Flow

How price lists resolve at sale time

1. Customer walks in → belongs to group "Wholesale"

2. POS checks active price list for that group

3. Scans product → checks quantity ordered

4. Applies matching tier price

5. Falls back to product base price if no match

PriceList lookup is a Redis-cached hot path at POS

Backend Changes Required

Price Lists only New entity, repository, service, controller, DTOs in product-service
Variants & Bundles Backend already complete — frontend work only

Frontend Changes Summary

Variants Enhance ProductDetailPage with variant matrix builder, variant image gallery, per-variant barcodes. Update sidebar route.
Bundles/Kits New BundlesListPage, enhance product form combo section, update sidebar + routes.
Price Lists New PriceListsPage, PriceListDetailPage, API layer, types, sidebar + routes.
