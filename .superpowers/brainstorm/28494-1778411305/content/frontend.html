Frontend Design

Shared document components that drop into every transactional page

Component Architecture
New Shared Components (in components/smartpos/documents/)
DocumentActionsBar.tsx
Button group: Preview | Print | Download PDF | Email | WhatsApp
Dropdown for more actions
Props: { documentType, referenceId, disabled }
DocumentPreviewModal.tsx
MUI Dialog showing PDF preview
Left: React-rendered HTML (instant)
Right toggle: actual PDF via Gotenberg
Actions in footer
DocumentEmailDialog.tsx
To, Subject, Message fields
Attachment preview
Send via POST /documents/{id}/email
DocumentWhatsAppDialog.tsx
Phone number, Message
Sends PDF link via POST /documents/{id}/whatsapp
DocumentStatusBadge.tsx
Chip: Draft | Sent | Approved | Paid | Cancelled
Color-coded with watermark preview
TemplatePreviewRenderer.tsx
React component that renders Handlebars template
Used for instant preview in DocumentPreviewModal
Handles: placeholders, loops, conditionals, QR codes

Integration Pattern (consistent across all pages)
<DocumentActionsBar
  documentType="quotation"
  referenceId={sale.id}
  onGenerate={(doc) => showNotification(...)}
/>

One component. One line per page. Consistent UX everywhere.
