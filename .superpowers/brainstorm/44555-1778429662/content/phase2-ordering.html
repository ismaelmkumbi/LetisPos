Phase 2 — Build Order

6 subsystems. Which should we build first?

1

Remaining 20+ Document Types

Stock transfer, stock count, journal vouchers, payslips, contracts, work orders, service reports, expense vouchers, RFQs, supplier invoices, debit notes, GRNs, delivery manifests, barcode labels, price tags, and more. Pure .hbs template work — no new architecture.

2

QR Codes on Documents

Payment links, invoice verification URLs, e-invoice references, tracking links. Generated server-side as SVG/data-URI, embedded in templates as {{qr_code}} placeholder. Zero frontend work needed.

3

Visual Template Editor

Block-based editor with live preview. The biggest Phase 2 feature. Depends on template system from Phase 1.

4

Bulk Document Generation

Select multiple records → generate all PDFs → zip download or email batch. Async queue with progress tracking. Needs the async job pattern from report-service.

5

Document Version History

Track every generated document revision — who created, when, what changed. Re-print historical versions. Audit trail for compliance.

6

Template Versioning & Rollback

Git-like history for template edits. See what changed, who changed it, roll back to any previous version. Stored in template_versions table.
