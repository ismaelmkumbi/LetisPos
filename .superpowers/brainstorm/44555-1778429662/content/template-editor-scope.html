Visual Template Designer — How powerful should it be?

This determines the complexity of the editor. Simpler = faster to build but less flexible.

A

Code Editor (Monaco/CodeMirror)

Handlebars HTML editor with syntax highlighting, live preview panel, and placeholder autocomplete. Developers and tech-savvy admins edit templates directly. No drag-and-drop.

Pros

  • 1-2 days to build
  • Full power of HTML/CSS/Handlebars
  • No new backend complexity
  • Matching what ERPNext does

Cons

  • Not for non-technical users
  • No visual layout tools
  • Users must know HTML
B

Visual Block Editor

Sections-as-blocks: Header, Meta, Items Table, Totals, Footer, Signatures. Each block has toggles and style pickers. Drag to reorder blocks. No freeform layout — predefined blocks only.

Pros

  • Non-technical admins can use it
  • Consistent document quality
  • ~1 week to build
  • Mobile-friendly settings panel

Cons

  • Limited to predefined blocks
  • Can't add custom sections
  • Design system lock-in
C

Full Drag & Drop Designer (GrapesJS)

Full WYSIWYG with GrapesJS or similar. Drag components, resize, style with property panels. True visual editing with Handlebars placeholders as special elements. Like Stripe's email builder.

Pros

  • World-class editing experience
  • Anyone can design documents
  • Export HTML/CSS templates

Cons

  • 2-3 weeks to build + integrate
  • GrapesJS is heavy (~200KB gzipped)
  • Complex to save/load template blocks
  • Risk of broken layouts
