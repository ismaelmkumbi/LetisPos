Subsystem 3: Visual Template Editor (Block-Based)

Admins customize document layouts by toggling and reordering predefined blocks

Block Types (7 predefined blocks)
📋 Header Block
Logo (upload/URL), company name, TIN, address, phone, email. Toggle each field on/off.
📄 Meta Block
Document number, date, due date, reference, customer/supplier info. Field visibility toggles.
📊 Items Table Block
Column toggles: #, description, qty, unit price, tax%, discount, total. Column order via drag.
💰 Totals Block
Subtotal, discount, tax lines, grand total. Toggle each line. Currency formatting options.
✍️ Signature Block
Prepared by, approved by, customer acceptance, date. Configurable label text, 1-3 signature slots.
📝 Terms Block
Terms & conditions text area, validity period notice. Rich text or plain text option.
📦 Footer Block
Company info repeat, bank details, page numbers, generation timestamp. Toggle each element.

Technical Approach
Storage: Block config saved as JSON in template_overrides.body_html (already TEXT). The JSON describes which blocks are active, their order, and their settings. The backend compiles this JSON into actual Handlebars HTML at render time.

Example JSON config for quotation: 
{
  "blocks": ["header", "meta", "items", "totals", "validity", "signature", "footer"],
  "header": { "showLogo": true, "showTin": true, "showPhone": true },
  "meta": { "showDate": true, "showValidUntil": true, "showPreparedBy": true },
  "items": { "columns": ["#", "name", "qty", "unitPrice", "taxRate", "total"] },
  "totals": { "showSubtotal": true, "showDiscount": true, "showTax": true },
  "signature": { "slots": ["Prepared By", "Customer Acceptance", "Date"] }
}
